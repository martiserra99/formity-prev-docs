# React Hook Form

Learn how to integrate Formity with React Hook Form with an example implementation.

## React Hook Form

Formity works alongside [React Hook Form](https://react-hook-form.com/). To see how the integration works, you will need to navigate to the following folder in the `formity-prev-docs-code` repository. Clone it first if you haven't already.

```bash
git clone https://github.com/martiserra99/formity-prev-docs-code
cd formity-prev-docs-code/@formity/react/v2/react-hook-form
```

Make sure you run the following command to install all the dependencies.

```bash
npm install
```
