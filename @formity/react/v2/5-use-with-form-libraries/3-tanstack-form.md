# TanStack Form

Learn how to integrate Formity with TanStack Form with an example implementation.

## TanStack Form

Formity works alongside [TanStack Form](https://tanstack.com/form/latest). To see how the integration works, you will need to navigate to the following folder in the `formity-prev-docs-code` repository. Clone it first if you haven't already.

```bash
git clone https://github.com/martiserra99/formity-prev-docs-code
cd formity-prev-docs-code/@formity/react/v2/tanstack-form
```

Make sure you run the following command to install all the dependencies.

```bash
npm install
```
