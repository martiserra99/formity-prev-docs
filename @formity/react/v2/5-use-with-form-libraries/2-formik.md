# Formik

Learn how to integrate Formity with Formik with an example implementation.

## Formik

Formity works alongside [Formik](https://formik.org/). To see how the integration works, you will need to navigate to the following folder in the `formity-prev-docs-code` repository. Clone it first if you haven't already.

```bash
git clone https://github.com/martiserra99/formity-prev-docs-code
cd formity-prev-docs-code/@formity/react/v2/formik
```

Make sure you run the following command to install all the dependencies.

```bash
npm install
```
